# 아맞다주차!

"아, 맞다! 어디 댔더라?" 하는 순간을 위해, 주차하고 나오면서 버튼 한 번으로 위치를 기억해 두는 개인용 안드로이드 앱.
외부 라이브러리 0개, APK 약 57KB. 내 폰에만 설치해서 쓰는 용도.

## 기능 (v2.4)

### 브랜드 테마
- **아맞다주차!**: 런처·위젯·퀵설정 타일·알림 채널까지 같은 이름으로 표시
- **야간 아스팔트 + 유도선 노랑**: 어두운 바탕에서 지금 주차한 위치와 선택한 구역이 즉시 눈에 들어오는 테마
- **새 아이콘**: 위치 핀 안의 느낌표로 "아, 맞다!"를 표현

### 주차 기록
- **주차장 프로필**: 우리 집·회사·부모님 댁처럼 주차장을 여러 개 만들고, 상단 이름을 탭해 전환
- **프로필별 구역**: 각 주차장마다 자주 쓰는 구역/기타 구역의 이름·개수·순서를 별도로 설정
- **자주 쓰는 구역**: 기본 B1-A ~ B3-B, 큰 버튼을 탭 한 번으로 저장
- **기타 구역**: 기본 B4-A ~ B5-B, 작은 버튼으로 표시 (원하면 모두 숨김)
- **직접 위치 입력**: 타 주차장은 주관식으로 위치 저장
- **지금 주차한 곳 카드**: 마지막 기록 구역 + 정확한 시각 + "n분/시간 전" 상대 시각 (화면 켜둔 동안 매분 자동 갱신)
- **최근에 댄 곳**: 현재 주차장·차량의 최근 5개 목록 표시
- **전체 주차 기록**: 설정에서 모든 기록을 열어, 삭제한 주차장/차량에 속한 기록도 확인·수정·삭제
- **기록 수정·메모**: 지금 주차한 곳의 **수정** 또는 최근 항목을 탭해 구역·주차장·차량·시각·메모 수정
- **출차 시간 알림**: 지금 주차한 곳 카드에서 30분/1시간/2시간 뒤 또는 원하는 시각으로 알림 설정
- **삭제**: 카드의 "삭제" 또는 수정 화면의 "삭제"로 기록 취소 (확인 다이얼로그 포함)

### 홈 화면 위젯
- 앱을 열지 않고 현재 주차장·현재 차량의 자주 쓰는 구역 원탭 저장 (설정 목록의 앞 6개)
- 현재 주차장 + 위치 + 시각을 위젯 상단에 표시, 탭하면 해당 맥락으로 앱 열림

### 차량 블루투스 자동 알림
- 여러 차량을 이름과 블루투스 이름으로 등록하고, 상단 설정에서 현재 차량 전환
- 등록된 차량 블루투스 연결이 끊기면(= 차에서 내리면) 해당 차량의 "주차 위치 기록" 알림
- 알림에 **해당 차량·현재 주차장**의 최근 구역 버튼이 붙어 있어 앱을 열지 않고 바로 기록 가능
- 재연결되면 해당 차량 알림만 자동 취소 (차량끼리 독립)
- 블루투스 이름을 비우면 수동 기록 전용 차량으로 사용할 수 있음

### 설정
- 지금 주차한 곳 카드의 **설정** 버튼에서 주차장과 차량 관리
- **주차장 관리**: 추가·이름 변경·삭제, 현재 주차장의 구역 관리
- **차량 관리**: 추가·전환·수정·삭제, 차량별 블루투스 이름 등록
- **전체 주차 기록**: 프로필·차량을 삭제한 뒤에도 과거 기록을 열어 수정·삭제
- **주차 구역 커스터마이징**: 자주 쓰는 구역/기타 구역을 한 줄에 하나씩 추가·수정·삭제하고 표시 순서 변경
- 자주 쓰는 구역은 1~30개, 기타 구역은 0~30개까지 저장 (이름은 24자까지, 중복 방지)
- 기본값으로 되돌려도 기존 주차 기록은 유지

### 체크 (습관)
- 반복할 일 등록 → 탭 한 번으로 오늘 체크/해제
- 연속 일수 + **최근 7일 도트**(●●○●●●●)로 한눈에 흐름 파악
- 길게 누르면 리마인더 설정 · 변경 · 해제, 항목 삭제
- **리마인더**: 설정한 시각까지 체크 안 했으면 알림 (이미 했으면 조용히 넘어감)
  - 알림의 **"지금 체크"** 버튼으로 앱을 열지 않고 바로 완료 처리
  - 재부팅해도 알람 자동 재예약되어 유지

### 퀵설정 타일
- 알림바 타일에 현재 주차 위치 표시, 탭하면 앱 열림

## 빌드

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1
```

결과물: `dist\AMatdaParking.apk`

Gradle 없이 Android SDK 도구를 직접 사용한다 (aapt2 → javac → R8 → zipalign → apksigner).
R8이 데드코드 제거/최적화를 수행하며, 유지 규칙은 `rules.pro`에 있다 (새 Activity/Receiver를 추가하면 여기에 -keep 추가 필요).
필요한 것: `ANDROID_HOME`의 SDK (build-tools 35.0.0, platform android-35), `JAVA_HOME`의 JDK.

## 폰에 설치 후 할 일

1. 앱을 한 번 실행해서 **권한 2개 허용** ("근처 기기" = 블루투스 감지용, "알림")
2. 홈 화면 빈 곳 길게 누르기 → 위젯 → **아맞다주차!** 위젯 추가 (4x3 크기 추천)
3. 알림바를 두 번 쓸어내려 타일 편집(연필 아이콘) → **아맞다주차!** 타일을 끌어다 추가
4. 알림이 안 오면: 설정 → 앱 → **아맞다주차!** → 배터리 → "제한 없음"으로 변경

## 커스터마이징

| 바꿀 것 | 위치 |
|---|---|
| 주차장 추가·전환 | 상단 주차장 이름 또는 **설정 → 주차장 전환** |
| 현재 주차장의 구역 이름·개수·순서 | **설정 → 현재 주차장 관리 → 구역 관리** |
| 차량·블루투스 이름 | **설정 → 차량 전환 / 현재 차량 관리** |
| 출차 시간 알림 | 지금 주차한 곳 카드의 **출차 시간 알림** 또는 기록 수정 화면 |
| 삭제한 주차장·차량의 기록 | **설정 → 전체 주차 기록** |

앱 화면에는 현재 주차장에 설정한 구역이 모두 표시된다. 홈 위젯은 크기가 고정되어 있어 현재 주차장의
자주 쓰는 구역 앞 6개만 표시하며, 6개보다 적게 설정하면 남는 버튼과 행을 자동으로 숨긴다.

## 주의

- **`debug.keystore`는 개인 서명 키다.** Git에 올리거나 공유하지 말고 안전한 곳에 백업한다. 키가 바뀌면 앱을 지웠다 다시 깔아야 해서 기록이 날아간다.
- 업데이트 버전을 만들 때는 `build.ps1`의 `$VersionCode`를 1 올리고 다시 빌드 → 폰에서 덮어서 설치 (기록 유지됨).

## 구조

```
app/
  AndroidManifest.xml
  src/com/ohdduck/parknote/  # 기존 설치 업데이트 호환성을 위한 내부 패키지
    MainActivity.java        # 앱 화면 (프로필·차량·구역·기록·체크)
    Store.java               # 주차장 프로필·차량·주차/습관 데이터 및 이전 데이터 이관
    ParkWidgetProvider.java  # 홈 화면 위젯
    BtReceiver.java          # 차량 블루투스 끊김 → 알림
    ParkingTimers.java       # 기록별 출차 알림 예약/해제
    ParkingTimerReceiver.java# 출차 알림 수신·표시
    Reminders.java           # 습관 리마인더 알람 예약
    ReminderReceiver.java    # 알람 수신 → 미체크 시 알림, 부팅 후 재예약
    ParkTileService.java     # 퀵설정 타일
  res/                       # 레이아웃, 위젯, 색, 아이콘
build.ps1                    # 원커맨드 빌드 스크립트
rules.pro                    # R8 유지 규칙 (새 컴포넌트 추가 시 -keep 필요)
```

데이터는 SharedPreferences에 저장:

- 새 주차 기록: `history` = `[{id, c: 차량ID, cn: 차량명, p: 주차장ID, pn: 주차장명, z, t, m: 메모?, due: 출차알림시각?}]` (최근 40개)
- 습관: `habits` = `[{n: 이름, r: 리마인더(0시 기준 분, -1=없음), days: ["yyyy-MM-dd" 최신순], lt: 오늘 체크 시각}]`
- 설정: `parking_profiles_v1` = 주차장별 구역 목록, `parking_vehicles_v1` = 차량별 블루투스 이름

v2.2 이하의 단일 구역 목록·차량 이름·기존 주차 기록은 처음 실행할 때 기본 주차장/기본 차량으로 자동 이관된다.

표시 이름은 **아맞다주차!**로 바뀌었지만, 기존 설치에서 기록·위젯·예약 알림을 그대로 이어가기 위해
내부 패키지명과 저장 키는 유지한다.
