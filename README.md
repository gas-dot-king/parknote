# 아맞다주차!

"아, 맞다! 어디 댔더라?" 하는 순간을 위해, 주차하고 나오면서 버튼 한 번으로 위치를 기억해 두는 개인용 안드로이드 앱.
외부 라이브러리 0개, APK 약 97KB. 내 폰에만 설치해서 쓰는 용도.

## 기능 (v3.2)

### 화면 구조 — 하단 탭 4개
- **홈 · 기록 · 위치 · 설정**으로 나뉜다. 예전에는 한 화면을 계속 스크롤하고
  나머지는 다이얼로그에 숨어 있었다 (전체 기록은 설정 메뉴 다섯 번째 항목이 유일한 통로였다)
- 탭 상태는 화면을 돌려도 유지되고, 알림·위젯으로 들어오면 홈으로 되돌아온다

### 홈 탭
- **히어로 카드**: 지금 주차한 곳을 금색 면 + 자동차 그림으로 크게. 기록이 없으면
  평범한 카드로 내려앉는다 (금색은 "저장됨"의 신호라서)
- **감지 상태 카드**: 시동(차량 블루투스 연결) · 위치 판정을 한 줄씩 보여 준다.
  "왜 자동 알림이 안 왔지"를 앱 안에서 확인할 수 있는 유일한 자리 — 탭하면 설정 탭의 준비 상태로 간다
- 그 아래는 예전과 같다: 층 × 구역 격자 → 직접 입력 → 나가기 전 체크 → 최근에 댄 곳

### 위치 탭 — 내 차까지
- **거리 · 방향 · 도보 시간**: "152m · 북동쪽 · 도보 약 2분"
- **나침반 화살표**: 폰을 돌리면 차가 있는 쪽을 계속 가리킨다 (회전 벡터 센서)
- **주소**: Geocoder로 좌표를 주소로 바꿔 보여 주고 탭하면 복사
- **지도 앱으로 열기**: `geo:` 인텐트로 기기에 설치된 지도 앱에 넘긴다
- **지도 타일은 그리지 않는다.** 타일을 띄우려면 지도 SDK와 INTERNET 권한이 필요하고,
  그러면 "좌표는 기기 밖으로 나가지 않는다"는 약속이 깨진다. 거리·방향·주소는 전부 기기 안에서 만든다
- 주차 기록에 좌표(`lat`/`lon`)가 v3.2부터 함께 저장된다. 새 측위는 요청하지 않고
  마지막으로 잡힌 좌표만 쓰므로 배터리 소모가 사실상 없다. 권한이 없거나 좌표가 낡았으면 안 붙는다
- 옛 기록·권한 없음·기록 없음 세 경우를 구분해 각각 다른 안내와 버튼을 띄운다

### 설정 탭 — 자동 감지 준비 상태
- 자동 기록에 필요한 조건 다섯 개를 **완료 / 확인 필요 / 사용 안 함**으로 한눈에 보여 준다
  - 알림 권한 · 차량 블루투스 등록 · 배터리 제한 없음 · 위치 권한 · 항상 위치 허용
- **설정하기**를 누르면 해당 시스템 화면으로 바로 간다. 배터리 최적화는 지금까지
  이 README의 "폰에 설치 후 할 일 4번"으로만 안내했는데, 앱을 깐 사람이 README를 읽을 이유가 없었다
- 위치로 알림 조절이 꺼져 있으면 위치 두 항목은 경고가 아니라 "사용 안 함"으로 표시한다
  (기본이 꺼짐이라, 안 쓰는 사람에게 빨간불을 띄우면 멀쩡한 앱이 고장 난 것처럼 보인다)
- 상태 점은 색뿐 아니라 글리프(✓ / ! / ·)도 함께 바뀐다

### 브랜드 테마
- **아맞다주차!**: 런처·위젯·퀵설정 타일·알림 채널까지 같은 이름으로 표시
- **야간 아스팔트 + 유도선 노랑**: 어두운 바탕에서 지금 주차한 위치와 선택한 구역이 즉시 눈에 들어오는 테마
- **새 아이콘**: 위치 핀 안의 느낌표로 "아, 맞다!"를 표현

### 첫 실행 온보딩
- 4단계로 **주차장 이름 → 격자 구성 → 차량 블루투스 → 권한**을 정하고 시작
- 격자는 층/구역 개수를 버튼으로만 조절하고 미리보기가 즉시 갱신 (타이핑 0회로 완료 가능)
- 차 블루투스는 **페어링된 기기 목록에서 선택** — 이름을 손으로 적어 오타가 나면 자동 알림이 조용히 안 뜨기 때문
- 업데이트 설치는 온보딩을 건너뛰고 기존 설정을 그대로 유지

### 주차 기록
- **층 × 구역 격자**: 대단지 아파트처럼 층만으론 못 찾는 주차장을 위해 구역까지 한 화면에서 탭 한 번에 저장
  - 층 B1·B2 + 구역 A·B → `B1-A`, `B1-B`, `B2-A`, `B2-B` 버튼이 자동 생성
  - 층을 비우면 구역 이름이 그대로 버튼이 되는 목록형 (작은 주차장용)
  - 층 최대 8개 × 구역 최대 8개
- **주차장 프로필**: 우리 집·회사·부모님 댁처럼 주차장을 최대 6개까지 만들고, 상단 이름을 탭해 전환
- **프로필별 격자**: 각 주차장마다 층·구역·기타 구역을 별도로 설정
- **구역 편집 (블록)**: 격자 위 **구역 편집**을 탭하면 층·구역·기타 구역이 실제 버튼과
  같은 모양의 **블록**으로 나온다
  - 블록을 **탭** → 이름 바꾸기 · 삭제
  - **길게 눌러 끌기** → 순서 바꾸기 (놓은 자리로 삽입)
  - 끝의 **+** → 추가. 상한에 닿으면 + 가 사라진다
  - 한 줄에 최대 4개. 아래 미리보기가 즉시 갱신되고, 화면을 돌려도 편집 중이던 내용이 남는다
  - 예전에는 여러 줄 EditText 세 개였다. "한 줄에 하나씩"을 사람이 지켜야 했고 순서를
    바꾸려면 텍스트를 잘라 옮겨야 했으며, 편집 중인 글자가 어느 버튼이 되는지 안 보였다
- **기타 구역**: 격자 밖의 자리를 작은 버튼으로 표시 (기본은 비어 있음 — 필요할 때만 채운다)
- **직접 위치 입력**: 타 주차장은 주관식으로 위치 저장
- **지금 주차한 곳 카드**: 마지막 기록 구역 + 정확한 시각 + "n분/시간 전" 상대 시각 (화면 켜둔 동안 매분 자동 갱신)
- **최근에 댄 곳**: 현재 주차장·차량의 최근 5개 목록 표시, 아래 줄에서 전체 기록으로 바로 이동
- **전체 주차 기록**: 설정에서 모든 기록을 열어, 삭제한 주차장/차량에 속한 기록도 확인·수정·삭제
- **기록 수정·메모**: 지금 주차한 곳의 **수정** 또는 최근 항목을 탭해 구역·주차장·차량·시각·메모 수정
- **출차 시간 알림**: 지금 주차한 곳 카드에서 30분/1시간/2시간 뒤 또는 원하는 시각으로 알림 설정
  - Android 절전 모드에서는 알림이 조금 늦을 수 있으며, 별도 정확한 알람 권한은 요청하지 않음
- **삭제**: 카드의 "삭제" 또는 수정 화면의 "삭제"로 기록 취소 (확인 다이얼로그 포함)

### 홈 화면 위젯
- 앱을 열지 않고 현재 주차장·현재 차량의 구역 원탭 저장 (6칸)
- 현재 주차장 + 위치 + 시각을 위젯 상단에 표시, 탭하면 해당 맥락으로 앱 열림

### 차량 블루투스 자동 알림
- 차량을 최대 3대까지 등록하고, 상단 설정에서 현재 차량 전환 (블루투스는 페어링 목록에서 선택)
- 등록된 차량 블루투스 연결이 끊기면(= 차에서 내리면) 해당 차량의 "주차 위치 기록" 알림
- 알림에 **해당 차량·현재 주차장**의 최근 구역 버튼이 붙어 있어 앱을 열지 않고 바로 기록 가능
- 재연결되면 해당 차량 알림만 자동 취소 (차량끼리 독립)
- 블루투스 이름을 비우면 수동 기록 전용 차량으로 사용할 수 있음

### 백업 · 복원
- **설정 → 백업 · 복원**에서 기록 전체를 JSON 파일 하나로 내보내고 되돌린다
- 문서 선택기(SAF)를 쓰므로 저장소 권한이 필요 없다
- 서명 키가 바뀌거나 폰을 바꿔 앱을 지웠다 깔 때 기록을 지키는 유일한 수단
- 가져오기는 현재 기기의 내용을 통째로 덮어쓰고, 예약된 알림도 다시 맞춘다

### 위치로 알림 조절 (기본 꺼짐)
- 주차장마다 좌표를 등록해 두면, 차에서 내린 곳이 **등록한 주차장 근처일 때만** 평소대로 알린다
- 그 밖에서는 무음 채널로 내려 알림함에만 남긴다 (회사·마트에서 매번 뜨던 알림 정리)
- **위치를 알 수 없으면 평소대로 알린다** — 알림을 놓쳐 주차 위치를 통째로 잃는 쪽이 훨씬 손해다
- 새 측위를 요청하지 않고 마지막으로 잡힌 좌표만 읽으므로 배터리 소모가 사실상 없다
  - 집 주차장이 지하라 그 자리에서는 어차피 위성이 안 잡힌다. 지하 진입 직전 좌표로 판정하고
    반경을 300m로 넉넉히 잡는 이유다. 30분 넘은 좌표는 없는 것으로 친다
- 등록된 주차장이 감지되면 그 주차장의 구역 버튼이 알림에 붙는다 (프로필 자동 전환)
- 블루투스 끊김은 브로드캐스트 수신이라 위치 권한을 **"항상 허용"**으로 둬야 한다
- 위치 코드는 전부 `Nearby.java`에 있고 스위치 하나로 완전히 비활성화된다

### 설정
- 하단 **설정** 탭. 항목이 주차장 / 차량 / 기록과 데이터로 묶여 있고, 각 줄에
  현재 상태가 부제로 붙는다 (예: 차량 관리 아래에 "내 차 · CAR-AUDIO")
- **주차장 관리**: 추가·이름 변경·삭제 (최대 6개), 현재 주차장의 구역 관리
- **차량 관리**: 추가·전환·수정·삭제 (최대 3대), 페어링 목록에서 블루투스 선택
- **전체 주차 기록**은 이제 별도 탭이다 (프로필·차량을 삭제한 뒤에도 열어 수정·삭제)
- **구역 커스터마이징**: 층·구역·기타 구역을 한 줄에 하나씩 추가·수정·삭제하고 표시 순서 변경
- 층은 0~8개, 구역은 1~8개, 기타 구역은 0~30개까지 저장 (이름은 24자까지, 중복 방지)
- 기본값으로 되돌려도 기존 주차 기록은 유지

### 체크 (습관)
- 반복할 일 등록 → 탭 한 번으로 오늘 체크/해제
- 연속 일수 + **최근 7일 도트**(●●○●●●●)로 한눈에 흐름 파악
- 길게 누르면 리마인더 설정 · 변경 · 해제, 항목 삭제
- **리마인더**: 설정한 시각까지 체크 안 했으면 알림 (이미 했으면 조용히 넘어감)
  - 알림의 **"지금 체크"** 버튼으로 앱을 열지 않고 바로 완료 처리
  - 재부팅해도 알람 자동 재예약되어 유지

### 퀵설정 타일
- 알림바 타일에 현재 주차 위치 표시, 탭하면 앱 열림

## 빌드

### 개발·직접 설치용 APK

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1
```

결과물: `dist\AMatdaParking.apk`

`build.ps1`은 Android SDK 도구(aapt2 → javac → R8 → zipalign → apksigner)로 직접 설치할 APK를 만든다.
버전·SDK·패키지 이름은 전부 `app/build.gradle`에서 읽으므로 두 빌드 경로가 어긋나지 않는다.

### 테스트와 검사

```powershell
.\gradlew.bat testDebugUnitTest lintDebug assembleDebug
```

유닛 테스트는 에뮬레이터 없이 JVM에서 돈다. 격자 역추론(`inferGrid`), 평면 목록 마이그레이션,
습관 연속 기록, 시각 표시, 백업 파일 검증을 덮는다 — 깨지면 기존 사용자의 데이터가 날아가는 자리들이다.
CI(`.github/workflows/android.yml`)에서 셋 다 돌린다.

### Google Play용 서명 AAB

출시용 업로드 키를 만든 뒤 `keystore.properties.example`을 `keystore.properties`로 복사해 실제 값만 로컬에 입력한다.
키와 비밀번호는 Git에 올리지 않는다.

```powershell
powershell -ExecutionPolicy Bypass -File build-release.ps1
```

결과물: `dist\AMatdaParking-release.aab`

Play 출시 절차, 스토어 문구, 개인정보 처리방침 템플릿, 테스터 안내는 [docs](docs/GOOGLE_PLAY_RELEASE.md)에 있다.
R8 유지 규칙은 `rules.pro`에 있다 (새 Activity/Receiver를 추가하면 여기에 -keep 추가 필요).
필요한 것: `ANDROID_HOME`의 SDK (build-tools 35.0.0, platform android-35), `JAVA_HOME`의 JDK.

## 폰에 설치 후 할 일

1. 앱을 한 번 실행해서 **첫 실행 안내 4단계**를 마친다 (주차장 격자 → 차 블루투스 → 권한 2개 허용:
   "근처 기기" = 블루투스 감지용, "알림")
2. 홈 화면 빈 곳 길게 누르기 → 위젯 → **아맞다주차!** 위젯 추가 (4x3 크기 추천)
3. 알림바를 두 번 쓸어내려 타일 편집(연필 아이콘) → **아맞다주차!** 타일을 끌어다 추가
4. 앱의 **설정 탭 → 자동 감지 준비 상태**에서 "확인 필요"가 남아 있으면 **설정하기**를 눌러 처리한다
   (배터리 제한 없음, 알림 권한 등 — 예전에는 이 항목을 여기 README로만 안내했다)

| 층·구역 이름·개수·순서 | 격자 위의 **구역 편집** (설정 탭 → 구역 편집도 동일) |
| 차량·블루투스 | **설정 탭 → 차량 전환 / 현재 차량 관리** |
| 출차 시간 알림 | 홈 히어로 카드 아래의 **출차 시간 알림** 또는 기록 수정 화면 |
| 삭제한 주차장·차량의 기록 | **기록 탭** |
| 자동 알림이 안 뜰 때 | **설정 탭 → 자동 감지 준비 상태** (홈의 감지 상태 카드를 눌러도 이동) |
| 차를 어디 뒀는지 찾기 | **위치 탭** |

앱 화면에는 격자 전체가 표시된다. 홈 위젯은 크기가 고정되어 6칸까지만 표시하는데, 격자가 그보다
크면 **최근에 쓴 구역**을 골라 담는다. 다만 배치는 격자 순서를 그대로 지키므로 주차할 때마다
버튼이 자리를 바꾸지 않는다. 직접 입력한 일회성 위치는 위젯에 올라오지 않는다.
6칸보다 적게 설정하면 남는 버튼과 행을 자동으로 숨긴다.

## 주의

- **`debug.keystore`는 개인 서명 키다.** Git에 올리거나 공유하지 말고 안전한 곳에 백업한다. 키가 바뀌면 앱을 지웠다 다시 깔아야 하는데, 그 전에 **설정 → 백업 · 복원 → 파일로 내보내기**를 해 두면 기록을 그대로 되살릴 수 있다.
- 업데이트 버전을 만들 때는 `app/build.gradle`의 `versionCode`를 1 올리고 다시 빌드 → 폰에서 덮어서 설치 (기록 유지됨).
  `build.ps1`도 이 값을 읽으므로 두 곳을 맞출 필요가 없다.

데이터는 SharedPreferences에 저장:

- 새 주차 기록: `history` = `[{id, c: 차량ID, cn: 차량명, p: 주차장ID, pn: 주차장명, z, t, m: 메모?, due: 출차알림시각?, lat?: 위도, lon?: 경도}]`
  (주차장×차량 맥락마다 20개, 전체 240개까지. 전역 40개였을 때는 차를 두 대 쓰면 한쪽 기록이 다른 쪽을 밀어냈다)
- 습관: `habits` = `[{n: 이름, r: 리마인더(0시 기준 분, -1=없음), days: ["yyyy-MM-dd" 최신순], lt: 오늘 체크 시각}]`
- 설정: `parking_profiles_v1` = `[{id, n, rows: 층[], cols: 구역[], sep, etc: 기타구역[], lat?, lon?, rad?}]`,
  `parking_vehicles_v1` = 차량별 블루투스 이름, `onboarded` = 첫 실행 안내 완료 여부,
  `location_filter` = 위치로 알림 조절 사용 여부

기록에 저장되는 `z`는 격자를 편 문자열(`"B2-C"`)이라 이전 버전의 기록과 그대로 호환된다.

v2.2 이하의 단일 구역 목록·차량 이름·기존 주차 기록은 처음 실행할 때 기본 주차장/기본 차량으로 자동 이관된다.
v2.5 이하의 평면 구역 목록(`main`)은 스키마 v5에서 층×구역 격자로 역추론된다. 완전한 곱집합이
아니면(예: `B1-A, B1-B, 지상`) 사용자가 쓰던 목록을 그대로 보존하는 1차원 구성으로 남는다.

표시 이름은 **아맞다주차!**로 바뀌었지만, 기존 설치에서 기록·위젯·예약 알림을 그대로 이어가기 위해
내부 패키지명과 저장 키는 유지한다.
