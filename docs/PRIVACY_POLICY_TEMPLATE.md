# 개인정보 처리방침 — 아맞다주차!

**시행일: [YYYY-MM-DD]**

아맞다주차!(이하 "앱")는 [개발자명]이 제공하는 주차 위치 기록 앱입니다.
이 문서의 대괄호 값을 실제 정보로 바꾸고, 공개 HTTPS 페이지에 게시한 뒤 Play Console과 앱 안에서 같은 URL을 안내해야 합니다.

## 1. 처리하는 정보와 목적

앱은 아래 정보를 사용자의 기기 안에 저장해 기능을 제공합니다.

- 주차장 이름, 주차 구역, 주차 시각, 메모, 출차 시간 알림
- 사용자가 위치 기능을 허용한 경우 주차장 좌표·반경과 주차 시점의 위도·경도,
  위치 측정 시각·정확도
- 차량 이름과 사용자가 등록한 블루투스 기기 이름
- 습관 이름, 리마인더 시각, 체크 이력
- 기록을 구분하기 위한 임의의 로컬 ID

현재 위치는 주차장 근접 판정, 차까지의 거리·방향 계산, 주차 시점 좌표 저장에 사용됩니다.
앱은 평소에 위치를 계속 추적하지 않습니다. 사용자가 **주행 중 위치 추적**을 켠 경우에만 등록한
차량 블루투스가 연결된 동안(주행 중) 위치를 받아 두며(그동안 진행 중 알림이 표시됨), 연결이 끊기면
즉시 중단하고 마지막 위치를 그 주차 기록에만 저장합니다. 저장된 정보는 주차 위치 표시, 차량별 블루투스 알림,
출차 시간 알림, 습관 리마인더 기능에만 사용됩니다.

## 2. 외부 전송·공유

앱은 인터넷 권한을 사용하지 않으며, 위 정보를 개발자 서버나 제3자에게 전송·판매·공유하지 않습니다.
광고 SDK와 분석 SDK도 사용하지 않습니다.

사용자가 **지도 앱으로 열기**를 직접 선택하면 저장된 좌표가 사용자가 선택한 외부 지도 앱에
전달되며, 그 이후 처리는 해당 지도 앱의 개인정보 처리방침을 따릅니다. **복사**를 선택하면
좌표가 Android 시스템 클립보드에 복사됩니다. 백업 내보내기는 사용자가 고른 문서 위치에
로컬 JSON 파일을 작성하는 동작이며 개발자에게 전송되지 않습니다.

## 3. 권한 사용

- **근처 기기(블루투스)**: 사용자가 등록한 차량 블루투스 기기의 이름과 연결/연결 해제 상태를 기기에서 확인해 주차 위치 기록 알림을 제공합니다. 권한을 허용하지 않아도 수동 기록 기능은 사용할 수 있습니다.
- **알림**: 출차 시간, 습관, 차량 블루투스 연결 해제 알림을 표시합니다. 권한을 허용하지 않아도 기록 기능은 사용할 수 있습니다.
- **위치(대략적인 위치 또는 정확한 위치)**: 사용자가 요청한 현재 위치 저장, 주차 시점 좌표 저장,
  저장된 차까지의 거리·방향 계산, 등록 주차장 근접 판정에 사용합니다. 정확한 위치를 허용할수록
  거리와 방향의 오차가 줄어듭니다. 위치 권한을 허용하지 않아도 좌표 없는 수동 기록은 가능합니다.
- **백그라운드 위치(항상 허용)**: 앱 화면이 열려 있지 않은 블루투스 연결 해제 순간에
  등록 주차장 근처인지 기기 안에서 판정하고, 사용자가 알림의 구역 버튼으로 저장할 때
  연결 해제 시점의 좌표를 붙이는 데 사용합니다. **위치로 알림 조절**을 끄면 근접 판정은
  중단됩니다. Android 설정에서 위치 권한을 회수하면 연결 해제 기록에는 좌표를 붙이지 않습니다.

## 4. 보관과 삭제

정보는 앱 전용 로컬 저장소에 보관됩니다. Android 자동 백업은 사용하지 않습니다.
개별 주차 기록과 습관 항목은 앱 안에서 삭제할 수 있으며, 전체 데이터는 Android 설정에서
`앱 → 아맞다주차! → 저장공간 → 데이터 삭제`를 선택하거나 앱을 삭제하면 제거됩니다.
사용자가 앱 밖의 문서 위치로 내보낸 백업 파일과 시스템 클립보드에 복사한 좌표는 앱 데이터
삭제로 제거되지 않으므로, 사용자가 해당 파일 또는 클립보드 내용을 별도로 관리해야 합니다.
