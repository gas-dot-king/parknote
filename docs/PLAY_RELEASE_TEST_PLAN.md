# 아맞다주차! 비공개 테스트 안내

테스터에게 아래 항목을 실제 차량/주차 상황에서 확인해 달라고 요청한다. 오류가 있으면 기기 모델,
Android 버전, 발생 시각, 재현 순서를 함께 받는다.

## 필수 확인

- [ ] 새 설치에서 온보딩이 **권한 → 차량 → 주차장 → 격자** 순서로 진행되고, 각 단계에서
  화면을 회전해도 입력 중인 값과 현재 단계가 유지되는지
- [ ] 첫 실행 후 수동으로 주차 구역을 저장하고, 앱을 다시 열어도 기록이 남는지
- [ ] 홈·기록·위치·설정 탭을 이동한 뒤 앱 밖에서 설정을 바꾸고 돌아왔을 때 현재 탭의 내용이
  즉시 갱신되는지. 홈이 아닌 탭에서 뒤로 가기를 누르면 먼저 홈으로 가는지
- [ ] 주차장 프로필과 차량을 여러 개 만들고 바꿔도 기록과 블루투스 연결 상태가 섞이지 않는지
- [ ] 기록 수정에서 구역·시각·메모·차량을 바꾼 뒤 정상 반영되고, 삭제한 주차장/차량의 기록도
  **기록 탭**에서 계속 확인·수정·삭제할 수 있는지
- [ ] 기록이 최대치에 가까울 때 기록 탭을 빠르게 스크롤해도 멈춤·잘못된 행 재사용이 없는지
- [ ] 출차 시간 알림을 설정·해제하고, 알림을 탭하면 해당 기록이 열리는지
- [ ] 알림 권한을 거부한 경우, 앱 전체 알림을 끈 경우, 일반·조용한 위치 기록 채널을 각각 끈
  경우를 시험해 준비 상태가 정확히 표시하며 **테스트 알림 보내기**가 성공했다고 잘못 안내하지 않는지
- [ ] 블루투스 권한을 거부하거나 "다시 묻지 않음" 상태여도 수동 기록이 동작하고,
  **설정하기**로 앱 권한 설정 화면을 열어 복구할 수 있는지
- [ ] 차량 블루투스 연결 해제 때 알림이 오는지, 재연결하면 그 차량 알림만 사라지는지
- [ ] 연결 해제 후 위치를 옮긴 다음 알림의 구역 버튼을 눌러도 해제 시점 좌표가 저장되는지.
  해제 시점에 좌표를 얻지 못했다면 나중 위치가 대신 저장되지 않는지
- [ ] 홈 화면 위젯과 퀵설정 타일에서 현재 주차장·차량·구역이 맞게 보이는지
- [ ] 6~8열 격자가 하나의 가로 스크롤 영역에서 잘리지 않고, 각 버튼을 누르기 쉬운 크기로
  유지하는지. TalkBack으로 구역 블록의 앞/뒤 이동 동작을 실행할 수 있는지
- [ ] 구역 편집 다이얼로그와 화면을 회전해도 저장 전 수정 내용이 유지되는지
- [ ] 휴대폰을 재부팅한 뒤 예약 알림과 기록은 유지되되, 재부팅 전 블루투스 연결 상태를
  현재 상태처럼 잘못 표시하지 않는지
- [ ] 위치 메타데이터가 든 최신 백업과 좌표 필드가 없는 이전 백업을 각각 복원해도 기록이
  정상 표시되고, 복원 전의 블루투스 연결 상태가 남지 않는지
- [ ] 블루투스가 없는 태블릿/Chromebook에서도 수동 기록 앱을 설치·실행할 수 있는지(가능하면)

## 위치 기능 확인

- [ ] 위치 권한 없음, 대략적인 위치만 허용, 정확한 위치 허용을 각각 시험하고 앱이 중단되지 않는지
- [ ] **현재 위치 다시 잡기**가 오래된 캐시를 그대로 돌려주지 않고 새 위치를 한 번 요청하며,
  탭을 벗어나거나 화면을 닫은 뒤 늦게 온 결과가 센서·화면을 다시 켜지 않는지
- [ ] 세로·가로 화면에서 나침반 방향이 실제 차 방향과 일치하는지
- [ ] 30분보다 오래된 좌표 또는 정확도 오차가 50m보다 큰 좌표에는 경고가 나오고,
  정확한 도착 문구와 나침반을 표시하지 않는지
- [ ] 좌표 복사는 로컬 좌표를 복사하고, 명시적으로 **지도 앱으로 열기**를 누를 때만 외부 지도
  앱 선택 화면 또는 지도 앱으로 좌표가 전달되는지
- [ ] **위치로 알림 조절**을 켤 때 전경 위치와 "항상 허용" 안내가 순서대로 나오고,
  거부해도 수동 기록은 계속 가능한지

## 알려진 동작

- 출차 시간·습관 알림은 Android 절전 모드에 따라 조금 늦어질 수 있습니다.
- 앱은 로그인·광고·분석·인터넷 권한을 사용하지 않습니다. 위치 기능을 선택하면 전경 위치와
  백그라운드 위치 권한을 사용할 수 있으며, 좌표는 기기 안에 저장됩니다. 사용자가
  **지도 앱으로 열기**를 직접 누른 경우에만 선택한 지도 앱으로 좌표를 넘깁니다.
