# 아맞다주차! 비공개 테스트 안내

테스터에게 아래 항목을 실제 차량/주차 상황에서 확인해 달라고 요청한다. 오류가 있으면 기기 모델,
Android 버전, 발생 시각, 재현 순서를 함께 받는다.

## 필수 확인

- [ ] 첫 실행 후 수동으로 주차 구역을 저장하고, 앱을 다시 열어도 위치가 남는지
- [ ] 주차장 프로필과 차량을 여러 개 만들고 바꿔도 기록이 섞이지 않는지
- [ ] 기록 수정에서 구역·시각·메모·차량을 바꾼 뒤 정상 반영되는지
- [ ] 출차 시간 알림을 설정·해제하고, 알림을 탭하면 해당 기록이 열리는지
- [ ] 알림 권한을 거부해도 수동 기록·기록 조회가 가능한지
- [ ] 블루투스 권한을 거부해도 앱이 정상 동작하는지
- [ ] 차량 블루투스 연결 해제 때 알림이 오는지, 재연결하면 알림이 사라지는지
- [ ] 홈 화면 위젯과 퀵설정 타일에서 현재 위치가 맞게 보이는지
- [ ] 휴대폰을 재부팅한 뒤에도 설정한 알림과 기록이 정상인지
- [ ] 블루투스가 없는 태블릿/Chromebook에서도 수동 기록 앱을 설치·실행할 수 있는지(가능하면)

## 알려진 동작

- 출차 시간·습관 알림은 Android 절전 모드에 따라 조금 늦어질 수 있습니다.
- 앱은 로그인, 광고, 분석, 위치(GPS) 권한을 사용하지 않습니다.
